## معرفی پروژه

**مهراد سام** یک سیستم مدیریت محتوای فارسی (Persian CMS) است که با **PHP خالص** (بدون فریم‌ورک) توسعه یافته. این پروژه برای شرکت خدمات کامپیوتری **مهراد** طراحی شده و شامل مجموعهٔ کاملی از ابزارهای مورد نیاز یک وب‌سایت شرکتی-فروشگاهی ایرانی است.

### ویژگی‌های کلیدی

- **قالب فارسی RTL** با پشتیبانی کامل از خط و زبان فارسی
- **فروشگاه آنلاین** با سبد خرید، درگاه‌های پرداخت ایرانی، و مدیریت سفارشات
- **چت زنده** با بازدیدکنندگان (Ajax Polling)
- **صفحه‌ساز** (Page Builder) با قابلیت درگ‌اند‌دراپ و حالت بوم آزاد
- **مدیریت قالب** (Theme Manager) با ویرایشگر فایل و شخصی‌سازی
- **ویرایشگر منو** با قابلیت جابجایی با Drag & Drop
- **مدیریت محتوا** (وبلاگ، صفحات، سرویس‌ها)
- **سیستم پیام‌رسانی چندکاناله** (تلگرام، واتساپ، بله، پیامک، پوش)
- **انجام خودکار بکاپ** از دیتابیس و فایل‌ها
- **مدیریت فایل** با نمایش درختی و آپلود
- **SEO داخلی** با متای اختصاصی
- **سیستم CAPTCHA** با محدودیت نرخ ورود (Rate Limiting)
- **پشتیبانی از چند زبان** (با قابلیت گسترش)

## اهداف و کاربردها

### کاربردهای اصلی

1. **وب‌سایت شرکتی** — معرفی شرکت، خدمات، نمونه‌کارها و تماس
2. **فروشگاه اینترنتی** — محصولات، دسته‌بندی، سبد خرید، پرداخت آنلاین
3. **وبلاگ و مجله** — مقالات، دسته‌بندی، برچسب‌ها
4. **پشتیبانی آنلاین** — چت زنده با کاربران
5. **سیستم مدیریت محتوا** — صفحات ایستا، سرویس‌ها، فرم تماس

### مخاطبان هدف

- شرکت‌های خدمات کامپیوتری و IT
- وب‌سایت‌های شرکتی با نیاز به فروشگاه
- توسعه‌دهندگانی که به یک CMS فارسی با معماری ساده نیاز دارند
- سایت‌هایی که روی هاست ایرانی با PHP 7.4+ اجرا می‌شوند

## فناوری‌های استفاده‌شده

| فناوری | کاربرد |
|---|---|
| **PHP 7.4+** (خالص، بدون فریم‌ورک) | تمام منطق پشتیبان — معماری شبه MVC، مسیریاب اختصاصی، MySQLi خام |
| **MySQL / MariaDB** از طریق **MySQLi** | پایگاه داده با utf8mb4 برای پشتیبانی فارسی |
| **Apache `.htaccess`** | بازنویسی URL |
| **HTML5 + CSS3** | رندر فرانت‌اند، چیدمان RTL |
| **JavaScript (خالص)** | تعاملات فرانت‌اند (بدون jQuery) |
| **Font Awesome 6.5** | کتابخانه آیکن |
| **Vazirmatn (WOFF2)** | فونت فارسی (میزبانی محلی) |
| **کتابخانه GD** (یا SVG) | تولید تصویر CAPTCHA |
| **Sortable.js** | جابجایی درگ‌اند‌دراپ در ادیتور منو |
| **bcrypt** (`password_hash`) | هش کردن رمز عبور |
| **JSON** (`site_settings.json`, `modir_tanzimat.json`) | ذخیره تنظیمات (فایل تخت، نه دیتابیس) |
| **Git** | کنترل نسخه + قابلیت به‌روزرسانی از پنل ادمین |

## بخش‌های اصلی

### ۱. هسته (Core) — پوشه `haste/`

شامل تنظیمات پایه، مسیریاب، و توابع عمومی. ابتدا `tanzimat.php` بارگذاری می‌شود که ثابت‌های دیتابیس، مسیرها و تنظیمات قالب را تعریف می‌کند. سپس `masiryab.php` بر اساس URL وارد شده، درخواست را به ماژول مناسب هدایت می‌کند.

**نحوه کار مسیریاب:**

```
URL ورودی        → ماژول مربوطه
─────────────────────────────────────
mod/...          → haste/mod/mod.php (پنل ادمین)
karbar/...       → haste/karbar/karbar.php (پنل کاربری)
khadamat/...     → mohtava/khadamat/khadamat-kontrol.php (سرویس‌ها)
mohtava/...      → mohtava/mohtava-kontrol.php (صفحات محتوا)
forushgah/...    → mohtava/forushgah/ (فروشگاه)
chat/...         → mohtava/gheychat/chat-kontrol.php (چت)
tarnegar/...     → mohtava/tarnegar/tarnegar-kontrol.php (وبلاگ)
tamas/...        → mohtava/tamas/tamas-kontrol.php (تماس)
home / ''        → صفحه اصلی (safhe_khane())
سایر مسیرها      → 404.php
```

### ۲. پنل مدیریت (Admin Panel) — مسیر `mod/*`

تمامی مسیرهای پنل ادمین در فایل `haste/mod/mod.php` و تابع `mod_route()` مدیریت می‌شوند. پنل ادمین از سه بخش تشکیل شده:

1. **هدر**: `ghaleb/ghmod/sarfaraz.php` (شامل نوار سرمه‌ای، منوی بالایی، page-bar)
2. **محتوا**: inline در هر case از switch
3. **فوتر**: `ghaleb/ghmod/panevis.php` (بستن تگ‌های HTML)

**مسیرهای پنل ادمین:**

| مسیر | عملکرد |
|---|---|
| `mod/dashmod` | داشبورد اصلی (آمار: مقالات، سفارشات، محصولات، پیام‌ها، چت) |
| `mod/lomod` | صفحه ورود با CAPTCHA |
| `mod/content` | مدیریت مقالات و مجلات |
| `mod/edit_content/{id}` | ایجاد/ویرایش محتوا |
| `mod/delete_content/{id}` | حذف محتوا |
| `mod/pages` | مدیریت صفحات ایستا |
| `mod/edit_page/{id}` | ایجاد/ویرایش صفحه |
| `mod/delete_page/{id}` | حذف صفحه |
| `mod/settings` | تنظیمات سایت (عمومی، اجتماعی، قالب، فروشگاه، فایل‌ها) |
| `mod/panel_settings` | تنظیمات نمایش پنل (رنگ، فونت، سایزها) |
| `mod/menu_editor/site` | ویرایش منوی سایت |
| `mod/menu_editor/admin` | ویرایش منوی پنل ادمین |
| `mod/chat` | مدیریت چت‌ها |
| `mod/messages` | مشاهده پیام‌های تماس |
| `mod/store/...` | مدیریت فروشگاه (محصولات، سفارشات، تنظیمات) |
| `mod/theme` | مدیریت قالب (لیست، فعال‌سازی، حذف) |
| `mod/theme/sections` | مدیریت بخش‌های قالب |
| `mod/theme/files` | ویرایش فایل‌های قالب |
| `mod/theme/custom` | شخصی‌سازی قالب (لوگو، رنگ، CSS) |
| `mod/theme/icons` | صفحه آیکن‌ها (Font Awesome) |
| `mod/builder/pages` | صفحه‌ساز (Page Builder) |
| `mod/files` | مدیریت فایل |
| `mod/backup` | پشتیبان‌گیری و بازگردانی |
| `mod/git_pull` | به‌روزرسانی از Git |

### ۳. سیستم قالب (Theme System)

قالب‌ها در پوشه `ghaleb/{name}/` ذخیره می‌شوند. قالب فعال در `site_settings.json` > `theme.active` ثبت می‌شود.

**ساختار یک قالب:**

```
ghaleb/{name}/
├── info.json         # ابرداده قالب (نام، توضیحات، نسخه)
├── sarfaraz.php      # هدر سایت (باز کردن HTML + CSS + منو)
├── panevis.php       # فوتر (بستن تگ‌ها + اسکریپت‌ها)
├── khane.php         # صفحه اصلی
├── tarnegar.php      # آرشیو وبلاگ
├── neveshteh.php     # صفحه مقاله
├── khadamat.php      # لیست سرویس‌ها
├── khadamat-tan.php  # جزئیات سرویس
├── tamas.php         # صفحه تماس
├── 404.php           # صفحه خطا
├── forushgah/        # صفحات فروشگاه
└── chat/             # صفحات چت
```

**قالب پیش‌فرض:** `mehrsam` — یک قالب شرکتی مدرن با طراحی RTL.

### ۴. فروشگاه (Store) — پوشه `mohtava/forushgah/`

فروشگاه آنلاین کامل با:
- محصولات با قیمت و تخفیف
- دسته‌بندی و برند
- سبد خرید (Session-based)
- ثبت سفارش با آدرس و اطلاعات تماس
- پرداخت آنلاین از طریق درگاه‌های ایرانی
- مدیریت سفارشات در پنل

**درگاه‌های پرداخت پشتیبانی‌شده:** زرین‌پال، آیدی پی، زیبال، نکست پی

### ۵. چت زنده (Live Chat) — پوشه `mohtava/gheychat/`

سیستم چت با تکنولوژی **Ajax Polling**:
- بازدیدکنندگان می‌توانند بدون ثبت‌نام چت کنند
- ادمین در پنل، چت‌ها را مدیریت می‌کند
- وضعیت‌ها: در انتظار / فعال / بسته شده

### ۶. صفحه‌ساز (Page Builder) — پوشه `mohtava/sakhtar/`

سیستم صفحه‌ساز بصری با قابلیت:
- بلاک‌های از پیش تعریف‌شده
- حالت بوم آزاد (Free Canvas)
- ذخیره داده‌ها به صورت JSON
- کش HTML برای سرعت
- قابلیت جایگزینی هدر/فوتر قالب

### ۷. اعلان‌رسان (Notification) — پوشه `afzuneh/elpayaagh/`

سیستم اعلان چندکاناله:
- **تلگرام** — ارسال پیام به ربات
- **واتساپ** — ارسال پیام از طریق API
- **بله** — پیام رسان بله
- **پیامک** — ارسال SMS
- **پوش (Push)** — اعلان مرورگر

### ۸. مدیریت فایل (File Manager) — `mohtava/file/file-manager.php`

مدیریت فایل‌های سرور با:
- نمایش درختی دایرکتوری‌ها

## سیستم مسیریابی

تمام درخواست‌های HTTP به `index.php` هدایت می‌شوند (از طریق `.htaccess`). سپس `masiryab_kon($url)` بر اساس بخش اول URL تشخیص می‌دهد که کدام ماژول باید اجرا شود.

```
درخواست مرورگر
      │
      ▼
  .htaccess: RewriteRule ^(.*)$ index.php?url=$1
      │
      ▼
  index.php
      │  require haste/tanzimat.php
      │  require haste/tavabe.php
      │  require haste/masiryab.php
      │
      ▼
  masiryab_kon($url)     ← بر اساس $url[0] (اولین بخش)
      │
      ├── mod/...      → haste/mod/mod.php::mod_route()
      ├── karbar/...   → haste/karbar/karbar.php
      ├── khadamat/... → mohtava/khadamat/khadamat-kontrol.php
      ├── mohtava/...  → mohtava/mohtava-kontrol.php
      ├── forushgah/...→ mohtava/forushgah/ (چند کنترلر)
      ├── chat/...     → mohtava/gheychat/chat-kontrol.php
      ├── tarnegar/... → mohtava/tarnegar/tarnegar-kontrol.php
      ├── tamas/...    → mohtava/tamas/tamas-kontrol.php
      ├── home/''      → khadamat-kontrol.php::safhe_khane()
      └── default      → 404.php
```

## سیستم قالب (Theme)

### نحوه کار

۱. فایل `haste/tanzimat.php` از `site_settings.json` می‌خواند که `theme.active` کدام قالب است.  
۲. ثابت‌های `GHALEB_FAAAL`، `MASIR_GHALEB` و `URL_GHALEB` تعریف می‌شوند.  
۳. هر صفحه، هدر (`sarfaraz.php`) و فوتر (`panevis.php`) قالب فعال را include می‌کند.  
۴. قالب می‌تواند از صفحه‌ساز برای هدر/فوتر پویا استفاده کند.

### شخصی‌سازی

- **رنگ‌ها**: متغیرهای CSS در `sarfaraz.php` از `site_settings.json` > `theme` خوانده می‌شوند
- **فونت**: وزیر (Vazirmatn) به صورت محلی و با CDN fallback
- **لوگو و فاوآیکن**: از پنل تنظیمات قابل تغییر
- **CSS/JS سفارشی**: از پنل شخصی‌سازی قالب

## نصب و راه‌اندازی

### نصب اولیه

۱. فایل‌ها را روی هاست آپلود کنید (ریشه وب).  
۲. در مرورگر به `http://yoursite.com/nasb.php` بروید.  
۳. مراحل ۴ گانه را طی کنید:  
   - **گام ۱**: خوش‌آمدگویی  
   - **گام ۲**: اطلاعات دیتابیس (ساخت خودکار)  
   - **گام ۳**: اطلاعات سایت و کاربر ادمین  
   - **گام ۴**: تأیید نصب  
۴. فایل `tanzimat.php`، `site_settings.json` و `modir_tanzimat.json` به صورت خودکار ساخته می‌شوند.  
۵. تمام مایگریشن‌های SQL اجرا می‌شوند.  
۶. **نکته امنیتی**: بعد از نصب، `nasb.php` را حذف کنید.

### انتقال از هاست دیگر

۱. در هاست قبلی از قسمت پشتیبان (mod/backup) بکاپ بگیرید.  
۲. بکاپ را از حالت زیپ خارج کنید و فایل‌ها را روی هاست جدید آپلود کنید.  
۳. `nasb.php` را اجرا کنید و گزینه "بازگردانی بکاپ" را انتخاب کنید.

### پیش‌نیازها

- PHP 7.4 یا بالاتر
- MySQL 5.7+ / MariaDB 10.3+
- Apache با mod_rewrite فعال
- حافظه: حداقل ۶۴ مگابایت

## قراردادهای پروژه

اطلاعات کامل در فایل `rahnamay.txt` در ریشه پروژه موجود است. مهم‌ترین قراردادها:

### ۱. نام‌گذاری فایل‌ها (فینگلیش)

همهٔ فایل‌ها باید به صورت **فینگلیش** نام‌گذاری شوند: کلمات فارسی با حروف لاتین.

| انگلیسی | فینگلیش (معتبر) |
|---|---|
| settings.php | tanzimat.php |
| install.php | nasb.php |
| router.php | masiryab.php |
| helpers.php | tavabe.php |
| admin_settings.json | modir_tanzimat.json |
| config.php | pikan_tanzimat.php |

### ۲. منوی پنل ادمین

- منبع حقیقی منو: فایل `haste/modir_tanzimat.json` > کلید `menu[]`
- ویرایش منو فقط در JSON انجام شود، نه در تابع پیش‌فرض
- برای جابجایی آیتم‌ها از ادیتور منو در پنل استفاده شود

### ۳. قوانین کدنویسی

- از کدگذاری UTF-8 بدون BOM استفاده شود
- از دستورات کوتاه PHP (`<?=`) مجاز است
- متغیرها و توابع به صورت فینگلیش نام‌گذاری شوند

## کتابچهٔ راهنما

### نحوه مشارکت

۱. مخزن را Fork کنید.  
۲. تغییرات خود را در یک شاخه (Branch) جدید اعمال کنید.  
۳. از قوانین پروژه (`rahnamay.txt`) پیروی کنید.  
۴. Pull Request ارسال کنید.

### نکات توسعه

- **اضافه کردن ماژول جدید**: فایل کنترلر را در `mohtava/` بسازید و مسیر را در `masiryab.php` ثبت کنید.
- **ساخت قالب جدید**: از پنل ادمین > مدیریت قالب > ساخت قالب جدید استفاده کنید. یا یک پوشه در `ghaleb/` با ساختار مشخص بسازید.
- **اضافه کردن آیکن به منو**: از صفحه آیکن‌ها (`mod/theme/icons`) کد آیکن را کپی کنید و در `modir_tanzimat.json` قرار دهید.
- **اضافه کردن درگاه پرداخت**: یک کلاس در `afzuneh/pardakht/` بسازید که رابط پرداخت را پیاده‌سازی کند.

### عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| صفحه سفید (White Screen) | فعال کردن `display_errors` در PHP یا بررسی `error_log` |
| خطای اتصال به دیتابیس | بررسی اطلاعات دیتابیس در `haste/tanzimat.php` |
| خطای ۴۰۴ برای همه صفحات | بررسی فعال بودن mod_rewrite در Apache |
| منوی ادمین نمایش داده نمی‌شود | بررسی `haste/modir_tanzimat.json` از نظر JSON معتبر |
| فونت‌ها نمایش داده نمی‌شوند | بررسی مسیر `ghaleb/manabe/fonts/` |

### کلیدهای میانبر پنل ادمین

- **Ctrl+S**: ذخیره در ادیتورها
- **Esc**: بستن مودال‌ها

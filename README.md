## قوانین اصلی پروژه

### ۱. نام‌گذاری فایل‌ها (فینگلیش)

فایل‌ها باید **فینگلیش** باشند (کلمات فارسی با حروف لاتین):

| انگلیسی (نادرست) | فینگلیش (درست) |
|---|---|
| settings.php | tanzimat.php |
| install.php | nasb.php |
| router.php | masiryab.php |
| helpers.php | tavabe.php |
| admin_settings.json | modir_tanzimat.json |

### ۲. ویرایشگر واحد

- **فقط صفحه‌ساز** (Page Builder) ویرایشگر رسمی تمام محتواست
- ویرایشگرهای HTML قدیمی حذف شده‌اند و نباید برگردند
- منوی جداگانه "صفحه‌ساز" وجود ندارد؛ داخل فرم ویرایش ادغام شده
- **محصول/وبلاگ:** فیلدهای ثابت بالا + صفحه‌ساز پایین
- **صفحه/خدمت:** صفحه‌ساز کامل

### ۳. خدمات = محتوا

- جدول `khadamat` منسوخ است
- خدمات با `posts.type='khadamat'` ذخیره می‌شوند
- از طریق `mod/services` مدیریت می‌شوند

### ۴. ریسپانسیو صفحه‌ساز

صفحه‌ساز ۶ حالت دارد (نباید حذف شوند):
- عریض (1920px) | دسکتاپ (1366px)
- تبلت افقی (1024px) | تبلت عمودی (768px)
- موبایل افقی (844px) | موبایل عمودی (390px)

### ۵. ساختار محتوا

فرم ایجاد/ویرایش هر نوع محتوا شامل دو بخش است:
1. فیلدهای پایه (بسته به نوع)
2. صفحه‌ساز برای محتوای بصری

### ۶. منوی پنل ادمین

- منبع حقیقی: `modir_tanzimat.json` > کلید `menu[]`
- برچسب‌ها **فارسی** باشند
- ویرایش فقط در JSON، نه در تابع پیش‌فرض

### ۷. اولویت منبع حقیقی

1. `rahnamay.txt`
2. `modir_tanzimat.json` و `tanzimat.php`
3. کد موجود در پروژه
